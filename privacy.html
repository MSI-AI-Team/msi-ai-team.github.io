Let's Read: privacy

Let's Read is a free learn-to-read app for young children, in English, Hindi and Gujarati. No ads, no purchases, no accounts.

What stays on the phone

A grown-up types a first name (or nickname) for each child, and the app keeps that name, the child's picture choice and which lessons are done. All of it is stored only on the phone, in the app's own storage. It is never sent to us or anyone else. Uninstalling the app, or clearing its data, deletes it.

What the app downloads

Lessons, pictures, songs and voice clips are downloaded from this website as the child needs them, or all at once when a grown-up taps "Save for offline". Downloading a file tells the website nothing about the child.

Microphone

This test version does not use the microphone. A grown-up confirms that the child has read a word by holding the ✓ button.

What we collect

Nothing. There is no sign-in, no analytics, no advertising, no tracking and no third-party code that collects data. Two outside services see the phone's internet address when files are downloaded, as with any website: GitHub Pages, which hosts the lesson files, and Google Fonts, which supplies the letter shapes. Neither is sent the child's name or anything the child does; see GitHub's and Google's privacy statements.

Children

The app is made for children aged 2 to 8 using it with a grown-up. Settings, the child list and anything that changes the app sit behind a "hold for 2 seconds" button meant for grown-ups.

Changes and contact

If this changes (for example, if a later version listens to a child reading), this page will say so before that version is released. Questions: use the developer contact on the app's Google Play page.
